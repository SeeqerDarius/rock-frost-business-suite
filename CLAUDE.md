# Claude Code production release requirement

The imported root `AGENTS.md` is mandatory for every Claude Code task in this
repository. Unless the user explicitly requests analysis, a draft, or
local-only work, a completed change must be production-ready, proportionally
validated, documented in `OPERATOR_HANDOFF.md`, committed, pushed, deployed,
and verified in production. Preserve unrelated concurrent work and stop before
production if a required gate fails or safe deployment is blocked.
